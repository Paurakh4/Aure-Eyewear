# Aure Eyewear

A modern, responsive static website for Aure Eyewear, showcasing eyewear products with a clean and elegant design.

## Description

This project is a static HTML website for an eyewear brand called Aure Eyewear. It includes various pages for browsing products, managing a shopping cart, user accounts, and contact information.

## Pages

- **index.html**: Landing page with featured products and navigation.
- **product-listing.html**: Displays a list of available eyewear products.
- **product-detail.html**: Detailed view of individual products.
- **shopping-cart.html**: Shopping cart functionality.
- **checkout.html**: Checkout process for purchases.
- **user-account.html**: User account management.
- **about-us.html**: Information about the company.
- **contact-us.html**: Contact form and information.

## Technologies Used

- **HTML5**: Structure of the website.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Inter Font**: Google Fonts for typography.
- **Material Symbols**: Icon library from Google Fonts.

## Features

- Responsive design that works on desktop and mobile devices.
- Dark mode support.
- Product browsing and details.
- Shopping cart functionality.
- User account management.
- Contact form.
